# Dunaevskie Plastinki

Мини-сайт интернет-магазина виниловых пластинок. 

Сайт представляет собой каталог виниловых пластинок для разной аудитории: от классики поп-панка (blink-182, Green Day) и эмо-рэпа (Lil Peep) до русского инди (Кишлак, Ногу Свело!).

#Страницы сайта
* `index.html` — Главная страница
* `catalog.html` — Каталог пластинок
* `price.html` — Прайс-лист
* `order.html` — Заказ под заказ
* `about.html` — О магазине
* `contacts.html` — Контакты
