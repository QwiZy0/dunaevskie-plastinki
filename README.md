# Dunaevskie Plastinki

Интернет-магазин виниловых пластинок. От поп-панка (blink-182, Green Day) и эмо-рэпа (Lil Peep) до русского инди (Кишлак, Ногу Свело!).

Проект создавался в рамках лабораторных работ по веб-разработке: от простого статического сайта до полноценного приложения с базой данных, авторизацией и обработкой логов.

Сайт на GitHub Pages:** [qwizy0.github.io/dunaevskie-plastinki](https://qwizy0.github.io/dunaevskie-plastinki/) *(доступна только статическая часть)*

---

## 🛠 Технологии
* **Frontend:** HTML5, CSS3, JavaScript (jQuery)
* **Backend:** PHP (MySQLi, PDO)
* **База данных:** MySQL (MariaDB)
* **Сервер:** Apache (XAMPP)

## Как запустить локально (XAMPP)

1. Установите XAMPP и запустите **Apache** и **MySQL**.
2. Настройте порт (если занят 80-й):
   * В панели XAMPP: `Config` → `Apache (httpd.conf)`.
   * Замените `Listen 80` на `Listen 8080`, а `ServerName localhost:80` на `localhost:8080`.
   * Перезапустите Apache.
3. В `httpd.conf` настройте `DocumentRoot` прямо на папку с проектом (или положите проект в `C:\xampp\htdocs`).
4. Откройте **phpMyAdmin** (`http://localhost:8080/phpmyadmin`).
5. Создайте базу данных `dunaevskie_db` (кодировка `utf8mb4_general_ci`).
6. Импортируйте в неё файлы по очереди (вкладка «Импорт»):
   * `database.sql` (таблицы для пользователей)
   * `lab5.sql` (таблица для логов)
7. Проверьте настройки подключения к БД в файле `config.php` (по умолчанию пользователь `root` без пароля).
8. Откройте сайт: **`http://localhost:8080/index.php`**

## Что реализовано 

### ЛР №1–3: Статика, семантика и фильтры
* Адаптивная верстка и единый стиль (`styles.css`).
* Семантические теги HTML5 (`header`, `main`, `article`, `footer`).
* Версия для печати (`print.css`) — переключается без перезагрузки страницы.
* «Умный фильтр» в каталоге: скрывает пластинки по жанру, десятилетию и наличию. Если выбор приводит к пустому результату, чекбокс блокируется.

### ЛР №4: Регистрация и авторизация
* Всплывающее модальное окно для входа и регистрации.
* Хэширование паролей (двойной MD5).
* Защита от SQL-инъекций и XSS-атак.
* Закрытый личный кабинет (`profile.php`) с возможностью смены ФИО и Email.
* Восстановление пароля через генерацию уникальной ссылки.

### ЛР №5: Обработка лог-файлов (Вариант 9)
* Загрузка лога Apache (`access.log`) в базу данных порциями через AJAX.
* Прогресс-бар с процентами, скоростью и количеством прочитанных строк.
* Отчет **«Объем скачанной информации за одну сессию»**.
* Сессия определяется как запросы с одного IP с паузой не более 20 минут.
* Реализована сортировка, группировка по часам/дням/неделям и клик по заголовкам таблицы.

## 🗂 Структура файлов (кратко)

| Файл / Папка | Назначение |
| :--- | :--- |
| `index.php` | Главная страница (с модалкой входа) |
| `catalog.html` / `script.js` | Каталог с умным фильтром |
| `profile.php` | Личный кабинет (закрытый раздел) |
| `logs.php` / `ajax_load.php` | Загрузчик лог-файла в БД |
| `report.php` | Отчет по статистике посещаемости |
| `config.php` | Основные настройки (БД, пути) |
| `*.sql` | Дампы структуры базы данных |
| `images/`, `uploads/` | Медиа-файлы и аватары |
| `inc/` | Системные файлы (подключение к БД, хелперы) |
